## 3. Daftar Kebalikan (Inverse Lists)

### A. Endpoint Backend yang Tidak Dipanggil Langsung oleh Fungsi API di Komponen UI
1. `GET /api/health`: Endpoint probe kesehatan sistem (digunakan oleh orchestrator/Docker/load balancer, bukan halaman React).
2. `POST /api/payments/webhook`: Webhook notifikasi gateway pembayaran (Midtrans/Xendit simulator), dipanggil oleh server gateway secara asinkron.
3. `GET /api/bookings/:idOrCode/export.ics`: Ekspor jadwal sewa dalam format kalender iCalendar RFC 5545, diakses melalui tag `<a href="..." download>` langsung di browser.
4. `GET /api/admin/bookings/export.csv`: Ekspor data booking dalam berkas CSV, diunduh langsung lewat tombol link `<CsvButton />`.
5. `GET /api/admin/reports/revenue?format=csv`: Ekspor CSV laporan pendapatan admin.
6. `GET /api/admin/reports/utilization?format=csv`: Ekspor CSV laporan okupansi armada motor.
7. `GET /api/admin/reports/top-motors`: Endpoint sub-laporan unit motor terpopuler (disiapkan untuk visualisasi analitik tingkat lanjut).
8. `GET /api/admin/reports/summary`: Endpoint ringkasan status sewa keseluruhan.
9. `POST /api/admin/settings/reset`: Endpoint reset pengaturan sistem ke nilai bawaan PRD.
10. `POST /api/admin/motorcycles/:id/images`: Endpoint upload multi-gambar multipart/form-data.
11. `PUT /api/admin/motorcycles/:id/images/order`: Endpoint pengurutan ulang foto galeri motor.
12. `DELETE /api/admin/motorcycles/:id/images/:imageId`: Endpoint penghapusan single image motor.
13. `GET /api/admin/documents/:userId/:type/file`: Endpoint streaming biner file privat dokumen KTP/SIM dengan audit logging.

### B. Tabel Basis Data yang Tidak Dipakai Repositori
**NIHIL (0 Tabel)**: Seluruh 25 tabel yang ada di dalam migrasi PostgreSQL (`users`, `user_documents`, `motorcycles`, `motorcycle_images`, `motorcycle_features`, `maintenance_blocks`, `pickup_locations`, `addons`, `promo_codes`, `promo_redemptions`, `bookings`, `booking_items`, `booking_timeline`, `booking_handovers`, `booking_returns`, `booking_notes`, `payments`, `payment_events`, `reviews`, `favorites`, `contact_messages`, `idempotency_keys`, `app_settings`, `audit_logs`, `schema_migrations`) aktif dipakai dan dikelola oleh minimal satu repositori atau runner migrasi.

### C. Kolom yang Dirujuk Kode vs Skema Basis Data
1. Kolom virtual yang dihitung di mapper (bukan kolom fisik tabel `bookings`):
   - `payment_status`: Dihitung dari relasi tabel `payments.status` dan tanggal `bookings.paid_at`.
   - `handoverInfo`: Dihubungkan secara relasional dari tabel `booking_handovers`.
   - `returnInfo`: Dihubungkan secara relasional dari tabel `booking_returns`.
   - `notes`: Dihubungkan secara relasional dari tabel `booking_notes`.
2. Kolom yang telah disinkronkan melalui migrasi 011–014:
   - `contact_messages.is_read` (tersedia di migrasi 014).
   - `motorcycles.odometer_km` (tersedia di migrasi 012).
   - `reviews.is_hidden`, `reviews.hidden_by`, `reviews.hidden_at`, `reviews.hidden_reason` (tersedia di migrasi 013).
   - `user_documents.reviewed_by` (tersedia di migrasi 013).
   - `maintenance_blocks.created_by` (tersedia di migrasi 013).
